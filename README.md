# AI Smart Campus Connect

## Quick Start

1. **Backend Setup**
   ```bash
   cd backend
   npm install
   ```
   Update `backend/.env` with your MongoDB URI, `JWT_SECRET`, and `GEMINI_API_KEY`.

2. **Run Backend Server**
   ```bash
   npm start
   ```
   Server runs on `http://localhost:5000`.

3. **Run Frontend**
   Open `frontend/index.html` using VS Code Live Server.
